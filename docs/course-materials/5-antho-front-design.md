本技能用于指导创建具有鲜明辨识度、可投入生产的前端界面，避免落入泛化的 “AI slop”（模板化、廉价、千篇一律的 AI 味）审美。实现结果应是真正可运行的代码，并对审美细节和创意选择保持极高关注。

用户会提供前端需求：一个要构建的组件、页面、应用或界面。他们也可能补充其用途、受众或技术约束等上下文。

## 设计思维

在开始编码前，先理解上下文，并承诺一个**大胆、明确**的审美方向：

- **Purpose（目的）**：这个界面要解决什么问题？谁会使用它？
- **Tone（调性）**：选择一个足够鲜明的极端方向：极致冷峻的极简、极繁混沌、复古未来主义、有机 / 自然、奢华 / 精致、玩具感 / 趣味化、编辑部 / 杂志风、粗野主义 / 生猛原始、装饰艺术 / 几何风、柔和粉彩、工业 / 功能主义等。你可以把这些风格作为灵感，但最终要设计出真正忠于该审美方向的方案。
- **Constraints（约束）**：技术要求（框架、性能、可访问性）。
- **Differentiation（差异化）**：什么会让它**令人难忘**？用户最终记住的那一个点是什么？

**CRITICAL**：选择一个清晰的概念方向，并以高度精确的方式执行它。大胆的极繁和克制的极简都可以成立，关键不在“强度”，而在于是否真正有意图、是否执行到位。

随后实现真正可运行的代码（HTML/CSS/JS、React、Vue 等），并确保它：

- 具备生产级质量且功能可用
- 在视觉上足够醒目且令人印象深刻
- 整体统一，并带有清晰的审美立场
- 在每一个细节上都经过精细打磨

## 前端审美指南

重点关注：

- **Typography（字体）**：选择美观、独特、有趣的字体。避免 Arial、Inter 这类泛化字体；优先选择能够显著提升界面气质、带有性格与辨识度的字体。可以将一款有强烈个性的展示字体与一款更克制、精致的正文字体配对使用。
- **Color & Theme（色彩与主题）**：坚定地执行一个统一的审美体系。使用 CSS variables 保持一致性。主导色明确、强调色锐利的配色，通常比平均分散、畏首畏尾的配色更有表现力。
- **Motion（动效）**：使用动画来塑造效果与微交互。对于纯 HTML，优先采用 CSS-only 方案；对于 React，在可用时使用 Motion 库。聚焦高影响力时刻：一次编排良好的页面加载动画，配合错峰揭示（`animation-delay`），往往比零散的微交互更能带来愉悦感。使用会带来惊喜的滚动触发与悬停状态。
- **Spatial Composition（空间构图）**：采用出人意料的布局。不对称。重叠。对角线流动。打破网格的元素。大面积留白，或者有控制的高密度编排。
- **Backgrounds & Visual Details（背景与视觉细节）**：创造氛围与层次，而不是默认退回纯色背景。加入与整体审美一致的环境效果与纹理。可以使用渐变网格、噪点纹理、几何图案、分层透明度、戏剧化阴影、装饰性边框、自定义光标、颗粒叠层等手法。

**NEVER** 使用泛化的 AI 审美套路，例如：过度使用的字体族（Inter、Roboto、Arial、系统字体）、陈词滥调的配色方案（尤其是白底紫色渐变）、可预测的布局与组件模式，以及缺乏上下文个性的模板化设计。

请创造性解读需求，做出令人意外但又贴合上下文的选择，让设计看起来像是真正为这个场景量身定制的。不要让不同设计长得都一样。可以在不同生成结果之间大胆切换浅色 / 深色主题、不同字体、不同审美方向。**NEVER** 反复收敛到那些最常见的安全选择（例如 Space Grotesk 这种已经被过度使用的字体）。

**IMPORTANT**：让实现复杂度与审美愿景相匹配。极繁设计需要更复杂的代码、更丰富的动画与效果；极简或精致设计则需要克制、精准，以及对间距、字体和细微质感的极端关注。优雅来自于把选定的愿景执行好，而不是来自于功能堆砌。
