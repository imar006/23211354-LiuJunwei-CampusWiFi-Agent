成员：刘俊伟 23211354、吴睿娜 23211361。指导教师：陈一帅。

## 打开方式

进入 `frontend` 文件夹，双击 `index.html`，使用 Edge 或 Chrome 打开即可。无需安装 Python、Node.js、第三方库或提供 API Key。请完整保留同目录的 `style.css`、`app.js`、`data.js`。

## 建议查看顺序

1. 浏览横向案例卡片，点击不同案例，观察选中框和问题同步变化。
2. 点击“回放样例”，阅读当前判断、支持证据、反证与限制。
3. 展开工具记录核对输入返回；点击“导出 Trace”保存 JSON。
4. 使用底部“记录”和“观测”入口；尝试方向键或手机窄屏。
5. 阅读 `前端界面设计文档.md`，了解参考来源、视觉规范与交付边界。

当前为可独立运行的前端预览，所展示的网络观测为模拟数据，样例来自预存规则输出。回放不会执行实时工具或大模型调用。后端完善、模型评测和最终实验报告属于后续工作，本次没有提交虚构的模型性能数字。
