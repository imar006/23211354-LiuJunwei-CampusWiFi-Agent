# 课程需求对照与验收矩阵

2026-11-04，新选题“楼门外WiFi已连接但无法上网调查”。此文件表示交付目标，非提前宣告全部合格。用户最新要求Word，按其参考文档风格；原始课程PDF格式仍有差异，最终说明需如实区分。

| 课程项 | 本项目落实 | 验收证据 |
|---|---|---|
| 明确角色/Incident/边界（4分） | 校园网运维；楼门外业务不可用；不凭模拟确定真实现场原因 | 报告背景、模拟标识、专业引用 |
| 多步Agent/架构（6分） | 用户→LLM→工具→证据→候选与反证→建议 | 架构图、真实协作运行、完整Trace |
| ≥2真实功能工具 | 快照读取、IP/子网核验、有效探测统计、近时同设备对比 | src/tools.py，输入输出及错误处理说明 |
| ≥1实际Skill（4分） | 接入、IP、DNS、授权、无线分层调查，反证与不确定性 | SKILL.md，C加载记录；B不加载 |
| ≥2假设及支持/反证（5分） | DNS、地址、认证、无线、数据冲突与缺失 | 每案evidence来源ID、counterevidence、limitations |
| 七部分报告 | 背景、架构、工具Skill、完整案例、评测、实现、总结 | Word正文七节，不塞完整代码 |
| 架构图、典型流程 | 自绘有编号标题解释 | 报告图，涵盖用户/LLM/Skill/工具/模拟数据/输出 |
| ≥5案例（6分） | 10案，覆盖正常、专业检查、错误线索、缺失、混杂与多因素 | observations与独立ground_truth |
| ABC比较 | 同观测；直接模型、模型工具、模型工具Skill | 新上下文真实输出，协议，逐案评分 |
| ≥2有意义指标 | 标签准确率、2条/案证据语义、严重误断言率、任务成功、工具次数 | 预冻结rubric，独立审阅及SHA绑定、evaluate.py |
| 结果表与图 | 全部真实运行统计，NA不冒充0 | 结果CSV/summary与分析图一一对应 |
| 失败或不理想案例 | 使用真实模型误判/过度断言/冗余调用或证据局限 | 原始输出引用；不虚构失败 |
| 最小完整系统（3分） | 用户输入→调查→工具证据→结论；demo/API/Codex模式如实区分 | 程序入口、前后端、配置和README |
| ≥2真实运行截图 | 实际用户输入/调查；工具输入返回/最终结论 | 截图不以绘制日志冒充，不冒称现场采集 |
| 完整源代码及材料 | Agent、Tools、Skill、入口、数据、评测、依赖、配置 | README及实际运行，禁止密钥 |
| 报告格式（2分） | 作者学号摘要、编号图表、参考资料；A4及建议字号篇幅 | 参考Word风格、最终渲染逐页检查；身份不编造 |
| 反思/AI辅助披露 | 解释LLM与确定性检查职责及学生待核验事项 | 真实分工说明，不虚构学生亲自操作 |
| ZIP | 文档、代码、案例、Trace和复现说明 | 清单检查；运行依赖缓存和秘密不打包 |

阶段：①冻结场景/数据/评测→②程序与工具测试→③盲测、独立语义审阅和结果重算→④报告引用真实记录、渲染检查和打包。优先完成证据闭环，不扩展为生产网管或无线攻击工具。
