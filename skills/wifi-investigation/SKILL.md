# 校园WiFi已连接但无法上网调查

适用：校园网工程师对模拟室内外终端快照作只读调查。连接WiFi仅说明已关联，不能说明DHCP、网关、DNS、认证或互联网正常。

专业知识：用ipaddress计算地址类别、前缀与网关是否同网段。169.254/16通常表示链路本地地址，不可据此单独证明DHCP服务器故障；网关不在子网也可能有特殊on-link路由。ping受ICMP策略影响，失败不等于HTTPS不可用。DNS成功不等于所有域名可用，HTTPS成功也只覆盖指定测试目标。

步骤：提出地址、DNS、认证、上游、无线等至少两个假设；按需get_snapshot确认原始记录，compare_snapshots核对同设备和时间间隔；再以check_ip_config验证地址、analyze_connectivity统计各层有效检查及冲突。无需机械重复所有查询。null和格式异常不应计作失败；样本有效率与成功率要区分。对支持证据找反证，如外部HTTPS成功限制完全断网假设。

验证：检查成功数/有效样本数，缺失样本单独保留。室内外不同时或不同设备不能将差异归因位置。SSID相同不等于同AP，BSSID变化不证明漫游失败。信号值弱与网关不稳定仅支持无线候选，也可能终端、争用或AP有问题，不定位干扰源。

不确定性：缺失关键指标时暂不能确定；多个独立失败可为mixed；同一记录自相矛盾先报告conflicting并核对时间和目标。禁止用只含信号的观察强推唯一根因。每条evidence声明source_ids对应本次真实工具call id；不冒认未调用工具结果。limitations说明模拟边界、目标与样本限制，建议人工补测而不执行修改。
